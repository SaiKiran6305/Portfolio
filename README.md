# Sai Kiran Dasari — Portfolio

Personal software engineering portfolio: backend, full-stack and applied AI work at Oracle, Amdocs, ISN and the University of North Texas, plus selected projects.

Live at [sai-kiran-dasari.vercel.app](https://sai-kiran-dasari.vercel.app).

## Technology

- Semantic HTML, responsive CSS, vanilla JavaScript (no build step)
- FormSubmit for contact form delivery
- Open Graph image and JSON-LD structured data for link previews and search

## Structure

```
index.html                 content and metadata
styles.css                 all styling
script.js                  scroll progress, active nav, mobile menu, contact form
assets/og-card.jpg         1200×630 link-preview image (LinkedIn, Slack, X)
assets/project-*.webp      real screenshots of projects
Sai-Kiran-Dasari-Resume.pdf
```

## Keeping it accurate

Experience bullets use the same claims as the resume; update both together. Project numbers appear only where the linked repository can reproduce them.

## Deployment

Static site, deployed with Vercel from the repository root. The canonical URL is set to the Vercel domain.
